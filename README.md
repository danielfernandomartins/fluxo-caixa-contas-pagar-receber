# 💰 Fluxo de Caixa — Contas a Pagar e Receber

Sistema em Python para controle simplificado de contas a pagar, contas a receber, pagamentos e geração de relatórios financeiros.

## Visão do projeto

A aplicação transforma rotinas administrativas e financeiras em um fluxo estruturado de software, organizando transações e consolidando informações úteis para acompanhamento operacional.

## Funcionalidades

- Cadastro de contas a pagar
- Cadastro de contas a receber
- Listagem de transações
- Baixa de pagamentos
- Geração de comprovantes em arquivo
- Consolidação de totais financeiros
- Relatórios de valores a pagar, receber e pagos

## Valor demonstrado

Este projeto evidencia capacidade de:

- Modelar processos administrativos
- Estruturar regras financeiras
- Organizar informações operacionais
- Aplicar orientação a objetos
- Automatizar controles manuais

## Tecnologias

**Python 3** • Programação Orientada a Objetos • Manipulação de arquivos • Relatórios

## Aplicação prática

A solução pode evoluir para um sistema com:

- Banco de dados
- Centro de custos
- Controle por vencimento
- Dashboard de fluxo de caixa
- Exportação para Excel
- API para integração com outros sistemas
